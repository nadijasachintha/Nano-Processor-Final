Overview

What We Built

⚙️
Core Processor
A 4-bit single-cycle processor with 8 general-purpose registers. Executes one instruction every clock cycle — fetch, decode, and execute all happen in one shot.
📋
Instruction Set
4 base instructions: MOVI, ADD, NEG, JZR. Extended version adds SUB, AND, OR, XOR, MUL, CMP — all encoded in 12 bits.
🔌
FPGA Deployment
Synthesised and tested on the BASYS3 board. LEDs display register values. 7-segment display shows multiplication results. BTNC resets the processor.
🧩
Modular VHDL
Every component — ROM, ALU, Register Bank, Decoder, Multiplier, Comparator — is a separate VHDL entity. Fully structural design from D flip-flops up.

Program Counter Loop
PC → ROM → Instr → Decoder → PC_next. On each slow_clk edge PC is updated. PC_Adder always computes PC+1. Address_Selector chooses between PC+1 and the jump address.
Single-Cycle Guarantee
Every combinational path settles within one 1Hz clock period. Fetch + Decode + Execute all happen in one cycle. No pipeline, no hazards, no stalls.
Extended Components (Parallel)
Multiplier, Comparator, and Logic Gates are wired directly to R1_out and R2_out. They run continuously and update immediately — no ROM needed, no clock dependency.
Clock: 100MHz → 1Hz
A counter counts to 49,999,999 and toggles slow_clk. 7-segment refresh runs at ~500Hz per digit so both digits appear lit simultaneously (multiplexing).
Core Components

Program Counter & Address Control

3-bit Program Counter
Three D flip-flops store the current instruction address (0–7). On every rising slow_clk edge it loads PC_next. RST forces all bits to 0 — program restarts from address 0.
PC_Adder — Always +1
A 3-bit adder built from Half Adders (B is always 0, carry-in always 1). Combinational — PC+1 is ready instantly. Used for normal sequential execution.
Address_Selector MUX
A 2-way 3-bit MUX. When J='0' it selects PC+1 (normal flow). When J='1' it selects the jump address JA from the decoder — extracted from instruction bits [2:0].
-- Jump decision in IDecoder if RCJump = "0000" then J <= Jump; -- '1' JA <= I(2 downto 0); -- addr bits else J <= NotJump; -- '0' end if; -- Address Selector (MUX) PC_next <= JA when J = '1' else PC_plus1; -- Clock Divider (100MHz → 1Hz) if count = 49_999_999 then slow_clk <= not slow_clk; count <= 0; else count <= count + 1; end if;
Why JZR R0 always jumps
R0 is permanently "0000". So RCJump is always "0000", J is always '1', and the jump always fires. This gives a free unconditional branch instruction.
Core Components

Register Bank — 3-to-8 Decoder

8 Registers (R0–R7)
R1–R7 are real Register_4bit components (four D flip-flops each). R0 is just a wire permanently assigned "0000" — no flip-flops, impossible to write to.
3-to-8 Decoder — One-Hot
Takes a 3-bit RegSel address and produces 8 EN signals, exactly one of which is '1'. This ensures only the selected register latches the DataBus value each clock cycle.
RegEnable — Master Kill Switch
During JZR, IDecoder sets REn="000". The top level converts this to RegEnable='0', which forces ALL EN signals to '0'. No register writes occur during JZR — ever.
-- 3-to-8 Decoder (one-hot) EN(0) <= RegEnable when RegSel="000" else '0'; EN(1) <= RegEnable when RegSel="001" else '0'; EN(2) <= RegEnable when RegSel="010" else '0'; -- ... repeats for all 8 -- R0 hardwired — no Register_4bit R0_out <= "0000"; -- RegWriteEn in top level RegWriteEn <= '0' when REn="000" else '1';

Load Selector (L signal)
L='1' during MOVI → immediate value bypasses ALU and goes directly onto DataBus. L='0' for all other instructions → ALU result flows through.
NEG uses R0 as operand A
Decoder hardcodes RSA="000" for NEG. MUX selects R0="0000" as operand A. ALU computes 0 − R = −R. No dedicated "negate" hardware needed.
Core Components

Add / Subtract Unit — The ALU

4-bit Ripple Carry Adder
Four Full Adders chained. Each Full Adder is built from two Half Adders. Carry ripples from bit 0 to bit 3. All four adders compute simultaneously — it is parallel hardware, not sequential.
Subtraction via 2's Complement
When OpS='1': B is XORed with "1111" (inverts all bits) and Cin is set to 1. This computes A + NOT(B) + 1 = A − B. No separate subtractor hardware needed.
Zero & Overflow Flags
Zero='1' when Result="0000" — used by JZR. Overflow fires when carry INTO the MSB differs from carry OUT of the MSB — signed wrap detected automatically.
-- B inversion for subtraction B_in <= B xor (OpS & OpS & OpS & OpS); -- Cin = OpS (1 for sub, 0 for add) RCA_4bit port map( A => A, B => B_in, Cin => OpS, Sum => Result, Cout=> Carry ); -- Zero detection Zero <= '1' when Result = "0000" else '0'; -- Overflow: carry-in MSB ≠ carry-out MSB Overflow <= Carry_3 xor Carry_out;
NEG = SUB from 0
A=0000 (R0), B=R, OpS=1 → Result = 0 − R. The ripple-carry adder does this for free. No hardware change needed between NEG and SUB.

Why NEG R1 gives −1
4-bit 2's complement: 0 − 1 = 1111 = 15 unsigned = −1 signed. Adding 15 to any 4-bit number is the same as subtracting 1 (modular arithmetic).
Loop structure
Addr 4–7 form a loop. Each iteration: R2 decrements by 1, R7 accumulates R2. After 3 loops: R7 = 3+2+1 = 6. When R2=0, addr 6 halts by jumping to itself.

3+15=2? — Modular arithmetic
R2=3 (0011), R1=15 (1111 = −1 in 4-bit). 0011+1111 = 1 0010. The carry out is discarded. Result = 0010 = 2. This is 3+(−1) = 2. Correct.

Fundamental Building Blocks

From Gates to Processor

🔀
D Flip-Flop
1-bit storage. Captures D on rising clock edge. RST clears async. Foundation of all registers.
➕
Half Adder
Sum = A XOR B. Carry = A AND B. No carry-in. Two gates, two outputs.
➕
Full Adder
Two half adders chained. Handles carry-in. Cout = C1 OR C2.
🔢
RCA 4-bit
4 full adders chained. Carry ripples bit-by-bit. Used in ALU and PC_Adder.
🔀
MUX 2-to-1
Selects between two inputs with a 1-bit control. Used in Address & Load Selectors.
🔀
MUX 8-to-1
Picks one of 8 register outputs. Two instances (MUXA, MUXB) feed ALU operands.
📦
Register 4-bit
4 D flip-flops + Enable gate. Only writes when Enable='1'. Holds value otherwise.
🔓
3-to-8 Decoder
One-hot: exactly one of 8 outputs goes high. Routes write enable to correct register.
💾
Program ROM
8×12-bit combinational memory. PC address in → 12-bit instruction out instantly.
🧠
IDecoder
Extracts all control signals from 12-bit instruction. Purely combinational. No clock.
✖️
Multiplier
4-bit × 4-bit → 8-bit. Combinational. Runs continuously on R1×R2. Shows on 7-seg.
⚖️
Comparator
Generates EQ, GT, LT flags from R1 vs R2. Three concurrent signal assignments.
